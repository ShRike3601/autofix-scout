# What is new in AutoFix Scout 0.3.1

- A new look: frosted glass on Windows 11, calmer type without bold text, and smoother movement. Buttons respond when you point at them and when you select them.
- This computer: the left panel shows the Windows version, processor, graphics card, memory, free disk space, battery and how long the computer has been running. "Copy details" copies them for the person helping you.
- Recent activity: the last checks and, when possible, an Undo for the latest change, directly in the left panel.
- What AutoFix Scout is doing: during a check, one line shows the current step. Select it to see every step, for example which event logs and settings were read.
- Settings now has its own panel that opens from any page, also during a check. New options: theme (dark, light or as Windows), accent colour, text size, frosted glass, reduce motion, show every step of a check, open the data folder and clear the history.
- The MSI Afterburner check no longer reports an overclock when Afterburner is only installed with its standard settings.
